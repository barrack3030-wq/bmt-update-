# Dokumen Laporan Keuangan

Folder ini digunakan untuk menyimpan dokumen laporan keuangan BMT Al-Muhajirin yang telah disetujui untuk dipublikasikan.

## Panduan
- Unggah dokumen dalam format PDF.
- Gunakan nama file yang jelas, misalnya `laporan-keuangan-2025.pdf` atau `laporan-rat-2025.pdf`.
- Pastikan dokumen telah disahkan dan mendapat persetujuan publikasi.
- Hapus atau samarkan NIK, nomor rekening, alamat, nomor telepon, tanda tangan, serta data pribadi anggota sebelum dipublikasikan.
- Jangan menyimpan laporan transaksi individual atau dokumen internal yang bersifat rahasia di folder publik ini.

File di dalam folder `public/` dapat diakses publik melalui website yang menggunakan folder tersebut sebagai aset statis.
